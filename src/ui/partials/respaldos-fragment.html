Respaldos

Administra las copias de seguridad de la base de datos del sistema (compras, almacén, calendarios, actividades y configuración).

Exportar base de datos

Genera una copia de la base de datos actual y la guarda en la ubicación que elijas. Úsala para resguardar tu información.

Importar base de datos

Reemplaza la base de datos actual por un archivo de respaldo (.db) que selecciones.

Esta acción sobrescribe todos los datos actuales y reinicia la aplicación. Asegúrate de exportar un respaldo antes si quieres conservar la información vigente.
